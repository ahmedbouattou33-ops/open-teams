## Secrets statement

The archive does not contain the real working .env values or private JWT keys. Therefore this archive cannot be claimed to include active secrets; those must be configured locally on the target machine. The retained .env.example files are templates only.

## Installation

After extraction: cd open-teams; pnpm install; run prisma generate for each Prisma service; copy and edit each .env.example with target hosts/ports; then docker compose up -d --build.
